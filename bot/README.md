# 🤖 Shopee/Lazada Affiliate Auto-Poster Bot (Lite)

ระบบโพสต์สินค้าแนะนำนายหน้า (Affiliate) อัตโนมัติด้วย Node.js, SQLite และขับเคลื่อนด้วย Gemini AI สำหรับการเจนข้อความป้ายยาภาษาไทยสุดตลกและน่าดึงดูด

---

## 🛠️ ขั้นตอนการเริ่มทำงานครั้งแรก (Quick Start)

### 1. ติดตั้ง Dependencies
เปิด Terminal หรือ Command Line ในโฟลเดอร์นี้ แล้วรันคำสั่ง:
```bash
npm install
```

### 2. สร้างระบบฐานข้อมูล SQLite
รันคำสั่งนี้เพื่อเริ่มสร้างโครงสร้างตารางข้อมูลในระบบหลังบ้าน:
```bash
npm run init-db
```
*คำสั่งนี้จะสร้างไฟล์ `affiliate_bot.db` ขึ้นมาและเพิ่มสินค้าตัวอย่างเข้าไปทดสอบ 1 รายการ*

### 3. ตั้งค่าคีย์ API
เปิดไฟล์ `.env` ขึ้นมาด้วยโปรแกรม Text Editor (เช่น Notepad) แล้วแก้ไขข้อมูล:
* ใส่รหัส `GEMINI_API_KEY` (รับคีย์ฟรีจาก Google AI Studio เพื่อเปิดใช้ AI เจนคำ)
* ใส่รหัส `LINE_NOTIFY_TOKEN` (สร้างฟรีจากเว็บ LINE Notify เพื่อใช้ส่งทดสอบเข้าแชทกลุ่มส่วนตัวของคุณ)
* หรือตั้งค่า Facebook Page Token หากคุณต้องการโพสต์เข้าเพจโดยตรง

---

## 📝 วิธีใช้งานระบบ

### 1. วิธีเพิ่มสินค้าเข้าคิวเพื่อรอโพสต์
ให้ใช้คำสั่ง `add_product.js` พร้อมพิมพ์ชื่อ ราคา และ ลิงก์สินค้าที่สนใจ เช่น:
```bash
node add_product.js "พัดลมพกพาลมแรงสะใจ ชาร์จ Type-C แบตอึดมาก" 189 "https://shopee.co.th/product-example-100"
```
*หมายเหตุ: ระบบมีตัวเช็คป้องกันการใส่สินค้าลิงก์เดิมซ้ำเพื่อไม่ให้ผู้รับข้อมูลรำคาญ*

### 2. วิธีการสั่งรันบอท (เพื่อดึงคิวไปโพสต์ 1 ชิ้น)
รันคำสั่ง:
```bash
npm start
```
บอทจะไปดึงสินค้าตัวที่เก่าที่สุดที่ยังไม่เคยโพสต์ ➡️ ทำการแต่งประโยคด้วย AI ➡️ แปลงลิงก์ ➡️ โพสต์ลงแชนแนลที่ตั้งค่าไว้ และทำเครื่องหมายในฐานข้อมูลว่าโพสต์เรียบร้อยแล้ว

---

## ⏰ วิธีตั้งค่าให้บอททำงานอัตโนมัติ 24/7 (โดยไม่ต้องเปิดคอมค้างไว้)

หากทดลองรันบอทในคอมพิวเตอร์ตัวเองจนมั่นใจแล้ว สามารถย้ายไปรันบนคลาวด์/เซิร์ฟเวอร์ราคาประหยัด:
1. เช่า Cloud VPS ราคาถูก (เช่น ของไทย ราคาเดือนละ 99 - 150 บาท) ติดตั้ง Node.js
2. ใช้เครื่องมือประเภท **Crontab (Linux)** หรือ **Windows Task Scheduler (Windows)** ในการรันคำสั่ง `node bot.js` ทุกๆ 1 หรือ 2 ชั่วโมง
3. หรือนำโปรเจกต์นี้เขียนวนลูปด้วยคำสั่ง `setInterval` รันค้างไว้ถาวรได้ทันที
