### 1.1 Type Definition และโครงสร้างข้อมูลของ Quiz Pool
- **ไฟล์ `src/lib/lessons-data.ts` (บรรทัด 1–8)**:
  ```typescript
  export interface PracticeQuestion {
    id: string
    question: string
    options: string[]
    correctAnswer: string
    explanation: string
    tip?: string
  }
  ```
  - `options`: เป็น Array ของ string 4 ตัวเลือก (`options.length === 4`)
  - `correctAnswer`: เป็น `string` ที่มีค่าตรงกับ 1 ใน `options` เป๊ะๆ (ไม่ใช่ตัวเลข index) เพื่อรองรับการสุ่มสลับตัวเลือก (shuffle) ได้อย่างปลอดภัย
  - `explanation`: บรรจุคำอธิบายวิธีคิด/หลักการ และเหตุผลที่ตัวเลือกถูกต้อง
  - `tip`: สรุปสูตรลัด 3 วินาที หรือจุดลวงที่ต้องระวัง

- **ไฟล์ `src/lib/dynamic-quiz-pool.ts` (บรรทัด 10)**:
  ```typescript
  export const DYNAMIC_QUESTION_POOL: Record<string, Record<string, PracticeQuestion[][]>> = { ... }
  ```
  - โครงสร้างเป็น 3 ชั้น: `[subject][moduleId][setIndex][questionIndex]`
  - `DYNAMIC_QUESTION_POOL[subject][moduleId][0]` = **Set B** (ชุดคำถามสำรองชุดที่ 1)
  - `DYNAMIC_QUESTION_POOL[subject][moduleId][1]` = **Set C** (หากมีชุดเพิ่มเติม)

### การกระจายความยากตาม Scaffolding Rule 16
ตามกฎ Rule 16 ใน `GEMINI.md` ข้อสอบทุกชุด 10 ข้อ ต้องออกแบบการไต่ระดับความยากแบบขั้นบันได 3 ขั้น:

| ลำดับข้อ | ระดับความยาก (Zone) | วัตถุประสงค์ & ลักษณะโจทย์ภาษาไทย | เทคนิค & จุดเน้น |
|---|---|---|---|
| **ข้อ 1–3** | **Confidence Builder**<br>(ปูพื้นฐาน & สร้างความมั่นใจ) | ทดสอบนิยาม หลักเกณฑ์เบื้องต้น และความจำตรงไปตรงมา เช่น อักษร 3 หมู่, ชนิดของคำพื้นฐาน, คำราชาศัพท์หมวดร่างกาย, สำนวนที่คุ้นเคย | ตัวเลือกชัดเจน ตัดช้อยส์ได้เร็วภายใน 15-30 วินาที เพื่อสร้างความมั่นใจก่อนเจอข้อลึก |
| **ข้อ 4–7** | **Application Zone**<br>(ประยุกต์ & ฝึกสูตรลัด 3 วิ) | นำหลักเกณฑ์ไปประยุกต์ใช้กับบริบทจริง เช่น การแยกประโยคความรวม/ซ้อนในบทความ, การแยกคำยืมภาษาต่างประเทศ, การหาใจความสำคัญย่อหน้า 5W1H | ฝึกสแกนสูตรลัด 3 วิ เช่น:<br>• บาลี vs สันสกฤต: เจอ ศ, ษ, ฤ, รร = สันสกฤตทันที<br>• ราชาศัพท์: ห้าม "ทรง" นำหน้ากริยาราชาศัพท์แท้<br>• กลอนสุภาพ: สดับไม่สามัญ รับจัตวา รองส่งสามัญตรี<br>• บุพบทนำหน้านาม สันธานเชื่อมประโยค |
| **ข้อ 8–10** | **Gifted Challenge**<br>(ห้องพิเศษ & ดักจุดลวง O-NET 10 ปี) | ข้อสอบระดับสอบเข้า ม.1 รร.ดัง (สวนกุหลาบ, สตรีวิทยา, บดินทรเดชา) และจุดลวงสถิติคนตอบผิด 70%+ ของ สทศ. | ดักจุดลวงยอดฮิต เช่น:<br>• "การเมือง/การบ้าน" ไม่ใช่อาการนาม (นามประสม)<br>• ภาษาใต้ "ชมพู่" แปลว่า "ฝรั่ง"<br>• กริยาเรียงกัน = ประโยคความเดียว ไม่ใช่ความรวม<br>• โคลงโลกนิติ ไม่ใช่ของสุนทรภู่ (กรมพระยาเดชาดิศร)<br>• อัตนัย สทศ. ห้ามใช้คำย่อเด็ดขาด (ร.ร. ❌) |

## 3. Caveats (ข้อพึงระวังและสมมติฐาน)

1. **Read-Only Scope**: รายงานฉบับนี้เป็นการสำรวจ วางผัง และเตรียมโครงสร้าง (Explorer Survey) โดยไม่มีการแก้ไขโค้ดต้นทางของระบบโดยตรง
2. **Set A vs Set B Separation**: Set B จะต้องไม่ใช่แค่การเปลี่ยนคำสลับตำแหน่ง แต่ต้องเป็นโจทย์สถานการณ์ใหม่ หรือตัวอย่างคำศัพท์ใหม่ที่วัดตัวชี้วัดเดียวกันเพื่อให้นักเรียนได้ฝึกทักษะรอบด้าน
3. **Diagnostic Explanation Standard**: ในทุกข้อ คำอธิบายเฉลย (`explanation`) จะต้องมีทั้ง (1) วิธีคิดและเหตุผลของคำตอบที่ถูกต้อง และ (2) การวินิจฉัยข้อผิด (Diagnostic Analysis) สำหรับ 3 ตัวเลือกที่ผิดอย่างครบถ้วน

| **1. thai_reading** | ข้อเท็จจริง vs ข้อคิดเห็น เบื้องต้น, หาใจความสำคัญประโยคแรก | 5W1H ในบทความสั้น, แยกโวหาร อุปมา/อุปลักษณ์, ความหมายโดยนัย (หมู, เก้าอี้) | จับผิดสถิติแฝงความเห็น, วิเคราะห์เจตนาแฝงผู้แต่ง, โวหารสัทพจน์/บุคลาธิษฐานซับซ้อน |
| **2. thai_word_classes** | แยกคำนาม สรรพนาม กริยา, ลักษณนามสัตว์และสิ่งของทั่วไป | สูตรแยก อาการนาม การ/ความ, บุพบทบอกสถานที่ vs สันธานเชื่อมประโยค | คำลวง: การบ้าน/การเมือง/ความแพ่ง (ไม่ใช่อาการนาม), คำว่า "ที่" ทำได้หลายหน้าที่ |
| **3. thai_royal_loanwords** | ราชาศัพท์หมวดร่างกาย (เนตร, กรรณ), คำสุภาพผลไม้/ปลา | สูตร "ห้ามทรงนำหน้ากริยาราชาศัพท์แท้", สแกน ศ, ษ, ฤ, รร = สันสกฤต | คำสมาสมีสนธิ (กลืนเสียง), ราชาศัพท์เจ้านายชั้นสูง (เสด็จพระราชดำเนิน vs เสด็จ), คำเขมรแฝง |
| **4. thai_sentence_structures** | ประโยคความเดียวประธาน+กริยา, จำแนกประธาน/กริยา/กรรม | สแกนคำเชื่อมความรวม (และ/แต่/หรือ) vs ความซ้อน (ผู้/ที่/ซึ่ง/อัน), ระดับภาษาทางการ | กริยาเรียงหลายตัวแต่เป็นความเดียว, ประโยคความซ้อนที่มีอนุประโยคซ้อน 2 ชั้น, ระดับภาษากึ่งทางการ |
| **5. thai_idioms_dialects** | สำนวนคุ้นเคย (กบในกะลา, น้ำขึ้นให้รีบตัก), ศัพท์ 4 ภาคเบื้องต้น (อู้, เว้า, แหลง) | แยกคำพังเพย (เปรียบเทียบ) vs สุภาษิต (สอนใจ), เทียบศัพท์ผลไม้ 4 ภาค (บักนัด, ยานัด) | ภาษาใต้: "ชมพู่" = ฝรั่ง, สำนวนวรรณคดี (ชักแม่น้ำทั้งห้า), สำนวนที่มีความหมายใกล้เคียงกันแต่ใช้ต่างบริบท |
| **6. thai_literature_poetry** | ฉันทลักษณ์กลอนแปดเบื้องต้น, ตัวละครหลักในศึกไมยราพและพลายงาม | ท่องเสียงท้ายวรรค: "สดับไม่สามัญ รับจัตวา รองส่งสามัญตรี", รสวรรณคดี 4 รส | สัมผัสระหว่างบท, ข้อคิดเชิงลึกศึกไมยราพ (ความกตัญญู vs หน้าที่), ที่มาโคลงโลกนิติ (กรมพระยาเดชาดิศร) |
| **7. thai_writing** | องค์ประกอบเรียงความ 3 ส่วน, หลักการย่อความสรรพนามบุรุษที่ 3 | โครงสร้าง 3 ท่อนทองคำอัตนัย, คำเชื่อมยกระดับคะแนน (นอกจากนี้, ส่งผลให้) | กฎเหล็ก สทศ. "ห้ามใช้คำย่อทุกชนิด (ร.ร. ❌)", การนับจำนวนบรรทัด 4-7 บรรทัดพอดี, เกณฑ์หักคะแนนอักขรวิธี |
| **8. thai_listening_speaking** | มารยาทในการฟังและดู, การตั้งใจฟังและไม่พูดแทรก | 3 จุดจับผิดโฆษณาเกินจริง (ทันทีใน 3 วิ, หายขาด 100%), การพูดโน้มน้าวใจ | โฆษณาแฝงและเจตนาชวนเชื่อ (Propaganda), วิเคราะห์ความน่าเชื่อถือของงานวิจัยที่โฆษณาอ้าง |

## 5. Verification Method (วิธีการตรวจสอบความถูกต้องอย่างอิสระ)

ทีมผู้พัฒนาหรือ Auditor สามารถตรวจสอบความสมบูรณ์และถูกต้องได้ดังนี้:

1. **ตรวจสอบความสอดคล้องของ Module IDs**:
   - ตรวจสอบว่า key ใน `src/lib/dynamic-quiz-pool.ts` (key `thai`) และ `src/lib/thai-lessons-data.ts` ตรงกันทั้ง 8 ตัว:
     `thai_reading`, `thai_word_classes`, `thai_royal_loanwords`, `thai_sentence_structures`, `thai_idioms_dialects`, `thai_literature_poetry`, `thai_writing`, `thai_listening_speaking`

2. **ตรวจสอบจำนวนข้อและความสมบูรณ์**:
   - `src/lib/thai-lessons-data.ts`: มี `practiceQuestions` ครบ 10 ข้อต่อโมดูล (รวม 80 ข้อ Set A)
   - `src/lib/dynamic-quiz-pool.ts`: มี `thai[moduleId][0]` ครบ 10 ข้อต่อโมดูล (รวม 80 ข้อ Set B)
   - รวมทั้งหมด 160 ข้อ

3. **ตรวจสอบ Type Safety และ Build**:
   ```bash
   npm run build
   ```
   ต้องไม่มีข้อผิดพลาด TypeScript Error ใดๆ

4. **ตรวจสอบ Diagnostic Explanation**:
   - ตรวจสอบว่าใน `explanation` ทุกข้อมีระบุเหตุผลว่าทำไมตัวเลือกที่ถูกต้องจึงถูก และทำไมตัวเลือกอื่นอีก 3 ตัวเลือกจึงผิด
   - ตรวจสอบว่า `correctAnswer` สะกดตรงกับ 1 ใน 4 สตริงใน `options` แบบ 100%
